Cadence is a music release planning tool for independent artists. The core idea: when one effort slips, everything downstream settles automatically.

## Locked vocabulary

Use these terms in product copy and docs. Do not invent synonyms.

| Term | Meaning |
| --- | --- |
| **Pursuit** | Not "project" |
| **Effort** | Not "task" (in user-facing copy) |
| **Exploration** | Loop-shaped work with no terminus; informs pursuits |
| **Handled** | Completion state language |
| **quiet season** | A lull / downtime period |
| **four-beat sensation pattern** | Health / status rhythm |

## What this site is for

This Mintlify site lives under [`mintlify/`](https://github.com/acknowledgements-sfc/cadence-cursor) in the app repo. Use it for product docs, guides, and API reference as they land.

Internal build logs and dispatches stay in the existing `docs/` folder — this site is the public-facing docs surface.
